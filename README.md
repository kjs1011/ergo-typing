# 자료 입력 자세 실험

[노트북 실험](https://kjs1011.github.io/ergo-typing/) · [태블릿 원본](https://kjs1011.github.io/ergo-typing/tablet.html)

실험 규칙 버전 3. A는 책상 왼쪽 태블릿 원본, B는 노트북 입력창 왼쪽 원본이다. 같은 입력창과 키보드를 쓰며 배치별 3회, 총 6회 수행한다. 원본은 16품목, 시행당 입력은 8개, 코드는 영문·숫자 교대 6글자다. 시행당 제한은 90초다.

## 무작위화와 시행

참가자 A01~A20은 AX→BY, BX→AY, AY→BX, BY→AX에 5명씩 사전 무작위 배정한다. 참가자별 시드로 원본 두 세트의 품목 순서와 코드를 생성한다. 원본은 블록의 세 시행 동안 유지하고, 시행마다 목표 8행과 표시 순서를 무작위로 정한다. 같은 반복 번호의 A·B는 목표 행 위치와 표시 순서를 맞춘다. 생성 규칙 버전은 2, 목표 행 규칙 버전은 2, 배정 규칙 버전은 1이다.

## 과업분석

목표는 여덟 품목의 코드를 정확히 옮겨 제출하는 것이다.

1. 입력 대상과 입력칸 확인
2. 원본에서 품목 탐색·코드 읽기
3. 코드 입력
4. 원본과 대조·수정

1→2→3→4를 반복하고, 불일치가 있으면 2→3→4로 돌아간다. 여덟 칸을 확인하면 제출한다. 90초가 되면 현재 값으로 종료한다.

입력 중 다음 보조 지표를 자동 기록한다. 단위는 초 또는 횟수이며 시선 추적은 사용하지 않는다.

| `task_log` 위치 | 의미 |
|---|---|
| 0 | 시작부터 첫 비어 있지 않은 문자 입력까지 시간 |
| 1 | 모든 8칸이 처음으로 각각 정규화 후 6글자를 충족한 시점 |
| 2 | 그 시점부터 제출·시간초과까지 시간 |
| 3 | 한 번 6글자를 채운 뒤 최초 값과 다른 값으로 편집한 입력칸 수(0~8) |
| 4 | 이전에 방문한 입력칸으로 초점이 다시 들어간 횟수 |

사건이 발생하지 않은 시간값은 `null`이다. 8칸 충족은 정답 판정을 뜻하지 않는다. 첫 입력 지연에는 탐색·읽기·조작이, 후반 시간에는 확인·수정·제출 조작이 섞인다. 입력칸 재방문은 시선 이동이나 원본 재확인 횟수를 직접 측정하지 않는다.

## 촬영 없는 작업자세 관찰

진행자 한 명이 각 블록 **첫 시행**에서 사전에 정한 두 장면을 관찰하고 종이에 적는다.

1. 첫 코드를 읽으려고 원본을 보는 순간
2. 첫 코드를 키보드로 입력하는 순간

각 장면의 고개·몸통을 기록한다. 자세를 지시하거나 멈추게 하지 않는다. 놓치거나 구분하기 어려운 장면은 미관찰로 남긴다. 블록의 설문 뒤 진행자가 기록을 옮긴다. 이 관찰은 전체 블록의 최빈·최악 자세가 아니며 정식 RULA 총점이나 조치수준을 산출하지 않는다.

`posture_observation`은 `[[원본 읽기 고개, 몸통], [코드 입력 고개, 몸통]]`이다.

| 부위 | 코드 |
|---|---|
| 고개 | 0 정면에 가까움, 1 아래로 숙임, 2 옆으로 돌림, 3 숙인 채 옆으로 돌림, 4 미관찰·판별 불가 |
| 몸통 | 0 뚜렷한 앞으로 기울임 없음, 1 앞으로 기울임, 2 미관찰·판별 불가 |

참가자의 블록 종료 자기보고 자세·목 불편감·작업부하는 관찰과 별도로 기록한다.

## 결과 형식

여섯 시행과 두 블록의 설문·관찰값을 끝에 한 번에 전송한다. 새 형식은 **실험 결과 v3**, **24열**, 참가자별 **6행**이다. 블록 설문과 관찰 리스트는 같은 블록의 세 행에 반복되므로 세 개의 독립 관찰로 세지 않는다. 기존 결과 탭은 유지한다.

`submitted_at`, `submission_id`, `participant`, `assignment`, `block`, `repetition`, `condition`, `source_set`, `elapsed_seconds`, `timed_out`, `correct`, `wrong`, `blank`, `posture`, `neck_after`, `rtlx`, `task_log`, `posture_observation`, `target_rows`, `item_names`, `responses`, `expected_codes`, `seed`, `versions`

리스트는 JSON 배열로 저장한다.

- `rtlx`: [정신적 요구, 신체적 요구, 시간적 요구, 수행도, 노력, 좌절감, 여섯 점수의 산술평균]. 각 항목 0~100점, 5점 간격. 수행도는 0 매우 잘함~100 매우 못함. 평균은 소수 둘째 자리까지 저장한다.
- `versions`: [실험 규칙, 코드 생성, 목표 행, 참가자 배정] = [3, 2, 2, 1].
- `target_rows`, `item_names`, `responses`, `expected_codes`: 입력 순서가 서로 대응하는 8개 값.

정답 판정은 앞뒤 공백 제거와 대문자 변환 후 한다. 시간초과는 90초로 기록하고 현재 응답을 정답·오답·빈칸으로 분류한다. 같은 제출 번호의 재전송은 중복 저장하지 않는다.

분석은 참가자 단위로 수행한다. 주 지표는 원본 읽기 관찰에서의 숙임 유무(고개 코드 1·3)이며 관찰 누락 쌍은 제외하고 수를 보고한다. 시간과 정확도, 반복별 입력 과정, 입력 단계 자세, 자기보고와 부담을 함께 살핀다. 짧은 과업의 범주 관찰로 장기 근골격계 질환 위험을 확정하지 않는다.

## 사전 점검

`?test=1`로 열면 건너뛰기를 사용할 수 있고 결과를 전송하지 않는다. 실제 참가자는 위의 일반 실험 링크를 사용한다.
