# 자료 입력 자세 실험

[노트북 실험](https://kjs1011.github.io/ergo-typing/) / [태블릿 원본](https://kjs1011.github.io/ergo-typing/tablet.html)

실험 규칙 버전 4. 참가자는 화면 안내에 따라 혼자 진행한다. A는 책상 왼쪽 태블릿 원본, B는 노트북 입력창 왼쪽 원본이다. 같은 입력창과 키보드를 쓰며 배치별 3회, 총 6회 수행한다. 원본은 16품목, 시행당 입력은 8개, 코드는 영문과 숫자가 번갈아 나오는 6글자다. 시행당 제한은 90초이며 전체 약 15분을 예상한다.

## 무작위화와 시행

참가자 A01~A20은 AX→BY, BX→AY, AY→BX, BY→AX에 5명씩 사전 무작위 배정한다. 참가자별 시드로 원본 두 세트의 품목 순서와 코드를 생성한다. 원본은 블록의 세 시행 동안 유지하고, 시행마다 목표 8행과 표시 순서를 무작위로 정한다. 같은 반복 번호의 A와 B는 목표 행 위치와 표시 순서를 맞춘다. 생성 규칙 버전은 2, 목표 행 규칙 버전은 2, 배정 규칙 버전은 1이다.

## 과업분석

목표는 여덟 품목의 코드를 정확히 옮겨 제출하는 것이다.

1. 입력 대상과 입력칸 확인
2. 원본에서 품목 탐색과 코드 읽기
3. 코드 입력
4. 원본과 대조하고 수정

1→2→3→4를 반복하고, 불일치가 있으면 2→3→4로 돌아간다. 여덟 칸을 확인하면 제출한다. 90초가 되면 현재 값으로 종료한다.

입력 중 다음 보조 지표를 자동 기록한다. 단위는 초 또는 횟수다.

| `task_log` 위치 | 의미 |
|---|---|
| 0 | 시작부터 첫 비어 있지 않은 문자 입력까지 시간 |
| 1 | 모든 8칸이 처음으로 각각 정규화 후 6글자를 충족한 시점 |
| 2 | 그 시점부터 제출 또는 시간초과까지 시간 |
| 3 | 한 번 6글자를 채운 뒤 최초 값과 다른 값으로 편집한 입력칸 수(0~8) |
| 4 | 이전에 방문한 입력칸으로 초점이 다시 들어간 횟수 |

사건이 발생하지 않은 시간값은 `null`이다. 8칸 충족은 정답 판정을 뜻하지 않는다. 첫 입력 지연에는 탐색과 읽기, 입력 조작이, 후반 시간에는 확인과 수정, 제출 조작이 섞인다. 입력칸 재방문은 시선 이동이나 원본 재확인 횟수를 직접 측정하지 않는다.

## 작업 자세 설문

각 블록에서 세 번 입력한 직후 참가자가 다음 두 상황의 고개 자세를 각각 한 가지씩 선택한다.

1. 품목을 찾거나 코드를 대조하려고 원본을 읽는 동안
2. 키보드로 코드를 입력하는 동안

보기는 정면에 가까움, 아래로 숙임, 옆으로 돌림, 숙인 채 옆으로 돌림, 기억이 불확실함이다. 세 시행 동안 가장 자주 취했다고 기억하는 자세를 선택하며 기억나지 않으면 불확실함을 고른다. 목 불편감과 작업부하도 같은 설문에서 응답한다. 자세 자료는 참가자의 회상 응답이며 관절각도와 자세 유지시간을 직접 측정한 값은 아니다.

## 결과 형식

여섯 시행과 두 블록의 설문을 끝에 한 번에 전송한다. 새 형식은 **실험 결과 v4**, **23열**, 참가자별 **6행**이다. 같은 블록의 설문 리스트는 세 행에 반복되므로 세 개의 독립 응답으로 세지 않는다. 기존 결과 탭은 유지한다.

`submitted_at`, `submission_id`, `participant`, `assignment`, `block`, `repetition`, `condition`, `source_set`, `elapsed_seconds`, `timed_out`, `correct`, `wrong`, `blank`, `posture`, `neck_after`, `rtlx`, `task_log`, `target_rows`, `item_names`, `responses`, `expected_codes`, `seed`, `versions`

리스트는 JSON 배열로 저장한다.

- `posture`: [원본 읽기 때의 고개 자세 응답, 키 입력 때의 고개 자세 응답]. 두 응답은 위 보기의 문자열로 저장한다.
- `rtlx`: [정신적 요구, 신체적 요구, 시간적 요구, 수행도, 노력, 좌절감, 여섯 점수의 산술평균]. 각 항목 0~100점, 5점 간격. 수행도는 0 매우 잘함~100 매우 못함. 평균은 소수 둘째 자리까지 저장한다.
- `versions`: [실험 규칙, 코드 생성, 목표 행, 참가자 배정] = [4, 2, 2, 1].
- `target_rows`, `item_names`, `responses`, `expected_codes`: 입력 순서가 서로 대응하는 8개 값.

정답 판정은 앞뒤 공백 제거와 대문자 변환 후 한다. 시간초과는 90초로 기록하고 현재 응답을 정답, 오답, 빈칸으로 분류한다. 같은 제출 번호의 재전송은 중복 저장하지 않는다.

분석은 참가자 단위로 수행한다. 주 지표는 원본 읽기 때 숙였다고 응답한 비율이며, 어느 블록이든 기억 불확실 응답이 포함된 쌍은 제외하고 수를 보고한다. 키 입력 때의 자세 응답은 별도로 비교한다. 시간과 정확도, 반복별 입력 과정, 목 불편감과 작업부하를 함께 살펴 과업 단계별 차이를 해석한다.

## 사전 점검

`?test=1`로 열면 건너뛰기를 사용할 수 있고 결과를 전송하지 않는다. 실제 참가자는 위의 일반 실험 링크를 사용한다.
